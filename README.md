# Tech Store
متجر إلكترونيات عربي تجريبي بتصميم RTL باستخدام Bootstrap 5 وJavaScript.

## تشغيل المشروع
افتح `index.html` في المتصفح أو انشر الملفات على استضافة مواقع ثابتة.

## إعداد واتساب
افتح `js/products.js` وعدّل:
`whatsappNumber: "201000000000"`
إلى رقم واتساب المتجر بصيغة دولية بدون علامة `+` أو مسافات.

## مهم قبل الإطلاق التجاري
- الأسعار والمنتجات الموجودة بيانات تجريبية ويجب مراجعتها واستبدالها.
- السلة والمنتجات في هذه النسخة محفوظة في LocalStorage على جهاز الزائر فقط.
- لوحة الإدارة تجريبية وغير محمية؛ لا تستخدمها لإدارة متجر حقيقي متعدد المستخدمين.
- لا توجد قاعدة بيانات مشتركة أو حفظ مركزي للطلبات في هذه النسخة.
- لإطلاق إنتاجي، اربط قاعدة بيانات مثل Supabase مع صلاحيات آمنة (RLS) ومصادقة مدير، وخادم/وظيفة آمنة لمعالجة الطلبات.
- تأكد من شروط الاستضافة وسياسة GitHub Pages قبل استخدامه لمتجر تجاري. يمكن استخدام Vercel أو Netlify للاستضافة الثابتة.
