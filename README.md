# Tech Store

متجر عربي RTL مبني باستخدام Bootstrap 5، ومتصل بقاعدة بيانات Supabase.

## إعداد الاتصال
تم إدخال Project URL وPublishable Key اللذين زودني بهما صاحب المشروع في `js/products.js`.
المفتاح Publishable مخصص للواجهة، ولا تضع أبداً Secret Key أو service_role في ملفات الموقع.

## إعداد قاعدة البيانات
1. تأكد من وجود الجداول الأساسية `categories`, `products`, `orders`, `order_items` حسب مخطط قاعدة البيانات الذي أنشأته.
2. افتح Supabase > SQL Editor ونفّذ `supabase-admin-setup.sql`.
3. من Authentication > Users أنشئ مستخدم المدير (البريد وكلمة المرور).
4. انسخ UUID الخاص بالمستخدم، ثم نفّذ في SQL Editor مع استبدال UUID:

```sql
insert into public.admin_users(user_id)
values ('ضع-UUID-مستخدم-المدير-هنا');
```

5. افتح `admin.html` وسجل الدخول بحساب المدير. لن يسمح الموقع بالإدارة إلا للحساب الموجود في `admin_users`.

## النشر
ارفع محتويات المجلد إلى مستودع GitHub، ثم اربط المستودع بـ Vercel أو Netlify.

## مهم قبل استقبال طلبات حقيقية
- غيّر `whatsappNumber` في `js/products.js` إلى رقم واتساب المتجر بصيغة دولية دون علامة +.
- المنتجات المعروضة تأتي من جدول `products` والأقسام من جدول `categories`.
- صور المنتجات حالياً تُدخل كرابط URL. يمكن إعداد Supabase Storage للرفع المباشر لاحقاً.
- زر إتمام الطلب يفتح واتساب برسالة جاهزة، لكنه لا يحفظ الطلب في جدول `orders` حتى الآن. لحفظ الطلبات وتحديث المخزون بشكل آمن، يلزم إعداد Edge Function تتحقق من السعر والمخزون من الخادم قبل الإدخال؛ لا تمنح الزوار صلاحية INSERT عامة على `orders` أو `order_items`.
- لا تعتمد على أسعار أو مخزون تجريبيين؛ أدخل بياناتك الحقيقية قبل النشر.
